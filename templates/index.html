Defense-in-Depth: Two Primary Cybersecurity Concepts

SecureStego pairs Steganography with Authenticated Encryption to achieve both secrecy of communication and confidentiality of content.

1. Steganography (Conceal Existence)

Derived from the Greek words for "covered writing", steganography hides the very existence of a secret message inside an innocent carrier file (a PNG image). An observer sees only a normal picture and has no reason to suspect covert transmission.

2. Encryption (Protect Confidentiality)

Encryption scrambles the message into unreadable ciphertext using a mathematical key. With AES-256-GCM, even if an adversary suspects that data is hidden in the image, they cannot read the message or tamper with it without the secret password.

Process Flow: Secret Text → AES-256-GCM → LSB Image Embedding → PNG Carrier → LSB Extraction → Decryption → Original Message
