AES-256-GCM

Galois/Counter Mode (GCM) provides Authenticated Encryption with Associated Data (AEAD).

  • Confidentiality: Encrypts with 256-bit symmetric security.
  • Integrity & Authenticity: Appends a 128-bit authentication tag. If even one bit of the ciphertext is changed, decryption fails immediately.
  • Random Nonce: Uses a fresh 96-bit nonce for each encryption to prevent replay and pattern leaks.

PBKDF2-HMAC-SHA256

Users remember passwords (strings), but AES requires high-entropy 256-bit binary keys.

  • Key Stretching: Runs 100,000 iterations of HMAC-SHA256 to slow down attacker brute-force or dictionary attempts.
  • Cryptographic Salt: Appends 16 cryptographically random bytes generated via os.urandom(16) to defeat pre-computed rainbow table attacks.
  • Non-persistent: The salt is stored in the header, while the password is never saved.

LSB Steganography

Least Significant Bit (LSB) replacement is a spatial-domain steganography technique.

  • Imperceptible: Changes only bit 0 of Red, Green, and Blue pixel color channels (e.g. changing 204 to 205). The human eye cannot detect this color delta.
  • Magic Header: Includes 4-byte b"SSTE" identifier so ordinary images are not misidentified.
  • Capacity Control: Enforces mathematical limits: $(W \times H \times 3) / 8$ bytes maximum payload.

Important Limitations & Security Considerations

Steganography is not a silver bullet. Understanding its limitations is vital for academic analysis and viva defense:

Lossy Compression Destroys Data Converting a stego PNG to JPEG or sharing it through platforms that compress images (e.g. WhatsApp standard mode, social media) discards fine high-frequency pixel variations, destroying the hidden bits completely.
Resizing, Cropping & Filters Any geometric transformation, color filter, or resizing recalculates pixel values using interpolation, which overwrites the least significant bits and breaks the payload.
Steganalysis Detection Advanced statistical tools (e.g. Chi-square test, sample pair analysis) can detect non-natural bit distributions in LSB planes. However, because the payload is encrypted with AES-256-GCM, the attacker can never read the message!

MCA 3rd-Semester Academic Division of Work

This project was structured into three distinct modular components to enable a group of three students to clearly divide the development and present their contributions during evaluation:

Student 1

Security & Encryption

Module: encryption.py

Responsible for key derivation using PBKDF2-HMAC-SHA256, salt generation, AES-256-GCM authenticated encryption, and tamper/integrity verification.

Student 2

Image Steganography Engine

Module: steganography.py

Responsible for Pillow image processing, RGB bit-plane manipulation, capacity calculation, magic header assembly, and binary bit extraction.

Student 3

Web Application & UI

Module: app.py & Templates

Responsible for Flask routing, in-memory processing, file upload validation, responsive cybersecurity interface, live previews, and automated test suite.
